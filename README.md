# 吃药打卡

一个每天记录一次吃药的小工具。单个网页，不需要安装，不联网也能用，**数据只保存在你自己的设备上，不会上传**。

## 怎么用

打开网页（网址见仓库的 Pages 设置，形如 `https://用户名.github.io/仓库名/`），吃完药点一下中间的大圆按钮即可。

在手机上打开后，用 Safari 的「分享 → 添加到主屏幕」，桌面上会出现一个「吃药打卡」图标，点开是全屏的，跟普通 App 一样。

## 功能

- 一键打卡，误点可撤销
- 日历上最近 3 天可补记
- 连续天数、本月完成率、最长连续
- 一键生成日历提醒文件（.ics），导入系统日历后每天定时提醒
- 导出 JSON 备份 / 导出 CSV 表格（可直接用 Excel 打开）

## 数据说明

记录存在浏览器本地，不会上传到服务器。手机上重新打开、离线打开都在，但清除浏览器数据会丢失，所以建议偶尔点一下「导出备份」。

换设备时，在旧设备「导出备份」、新设备「导入备份」即可。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 网页本体，全部功能都在这一个文件里 |
| `manifest.json` | 主屏幕图标、名称等设置 |
| `sw.js` | 离线缓存，断网也能打开 |
| `icon-*.png` | 桌面图标 |

修改网页后重新上传 `index.html` 即可，联网打开时会自动拿到新版本。
